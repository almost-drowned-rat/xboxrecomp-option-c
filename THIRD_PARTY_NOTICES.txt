THIRD_PARTY_NOTICES - xboxrecomp toolkit (Option C)
===================================================

Every release built with tools/release/port_release.ps1 or port_release_linux.sh carries this file. It lists the
third-party code compiled into a port built with this toolkit, with each part's copyright and licence. The
toolkit's own NOTICE (NOTICE-toolkit.txt in a release) says which file comes from where; the licence texts are
in licenses/ in a release (LICENSES/ in the toolkit).

-------------------------------------------------------------

  https://github.com/xemu-project/xemu

  src/apu/apu_core.c, apu_vp.c, apu_dsp.c, apu_regs.h, apu_state.h, apu_debug.h, xbox_adpcm.h, fpconv.h, apu.h,
  apu_shim.h (this project's own, same licence), src/nv2a_gl/gl_vsh_ff.c

    Copyright (c) 2012, 2015 espes
    Copyright (c) 2015, 2018-2019 Jannik Vogel
    Copyright (c) 2018-2025 Matt Borgerson

  GNU Lesser General Public License, version 2.1 or (at your option) any later version: the full text is
  licenses/LICENSE-xemu-parts-LGPL-2.1.txt.

  The APU files are built into the APU module, a shared library of its own next to the game (xbox_apu.dll /
  libxbox_apu.so), which can be replaced with one built from modified sources (licenses/source/SOURCE.txt).
  The complete corresponding source of these files as built into this release, including this project's
  changes, is in licenses/source/ (with SOURCE.txt: the toolkit commit, and how to rebuild the library and
  relink the game with a modified one).
